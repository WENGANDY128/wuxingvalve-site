2026 Valve Buying Notes: LNG activity + stricter fugitive-emission specs — what to put in your RFQ

2026-02-20 Valve selection Standards/Materials/Testing

Over the past two years, LNG/gas-related projects and long-term contracting have been noticeably more active. At the same time, environmental compliance is pushing fugitive-emission (low-leakage) requirements into everyday specifications. In practice, that means buyers ask tougher questions about packing design, test reports, materials, and documentation. A vague RFQ often leads to misquotes, repeated clarifications, longer lead time, and acceptance delays.

1) Why “low-emission” specs matter now

Many industries treat stem packing and gasket leakage as a compliance priority. You’ll increasingly see requirements such as ISO 15848, API 641, or TA Luft. For suppliers, the essentials are packing configuration, test evidence, and traceable QA documents.

2) LNG projects often bundle multiple requirements

LNG scopes commonly package standards (API/ASME/EN), Fire Safe (e.g., API 607), low-emission performance (e.g., ISO 15848 / API 641), and a complete documentation set (MTC/3.1, pressure tests, third-party inspection). The clearer your RFQ, the more accurate the quote and delivery plan.

3) 10 RFQ items that are often missing (copy/paste checklist)

  • Media (gas/steam/slurry/corrosive, etc.)
  • Pressure class (ANSI Class or PN)
  • Temperature range (min/max)
  • Valve type + size (ball/gate/globe/check; DN/NPS)
  • End connection (RF/RTJ/BW/SW/Thread; flange standard)
  • Materials (WCB/CF8M/alloy steel/duplex, etc.)
  • Sealing (soft seat / metal seat; stem sealing)
  • Low-emission requirement (ISO 15848 / API 641 / TA Luft, if required)
  • Fire Safe (API 607, if required)
  • Inspection & docs (MTC/3.1, NDE, pressure test, FAT, TPI)
